# Ложные срабатывания антивирусов

Exe на PyInstaller без подписи нередко ловится эвристикой. Порядок после каждого релиза:
1. Загрузить установщик на https://www.virustotal.com и вставить ссылку на отчёт в README (раздел «Проверка файла»).
2. По детектам отправить заявки: `microsoft.md`, `kaspersky.md`, `drweb.md`, `eset.md`, `avast-avg.md`, `other.md`.
3. Заявки отправляет владелец проекта вручную.
