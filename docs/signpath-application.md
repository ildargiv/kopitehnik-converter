# Заявка в SignPath Foundation (бесплатная подпись кода для открытых проектов)

Подаётся через форму на https://signpath.org/apply (условия: https://signpath.org/terms). Ниже готовые ответы. Отправляет владелец репозитория со своего аккаунта.

## Проект
- **Название:** KopiTehnik Converter (КопиТехник Конвертор)
- **Репозиторий:** https://github.com/ildargiv/kopitehnik-converter
- **Лицензия:** GNU AGPL-3.0 (открытая, файл `LICENSE` в корне)
- **Описание:** бесплатная программа для Windows для фотоцентров и типографий: пакетная конвертация фото и документов, цветокоррекция, листы для печати, редактор PDF с локальным распознаванием сканов, печать. Работает также как MCP-сервер для ИИ-агентов.
- **Сайт и новости:** https://vk.ru/icc_profil
- **Что подписываем:** `KopiTehnik-Converter-Setup.exe` (установщик, внутри `Converter.exe` и `Uninstall.exe`).
- **Сборка:** GitHub Actions, `.github/workflows/release.yml`, на серверах GitHub из открытого кода; к выпуску прикладываются `SHA256SUMS.txt` и аттестация сборки.

## Ответы на условия
- Проект открытый, зависимости тоже с открытыми лицензиями (список: `THIRD_PARTY_NOTICES.txt`).
- Программа не содержит вредоносного и нежелательного ПО и не собирает данные. Сеть используется только для проверки последней версии на GitHub и скачивания установщика по запросу пользователя; распознавание сканов локальное.
- Подписанные файлы выпускаются только из GitHub Actions по тегу в основной ветке; каждый запрос на подпись подтверждает владелец вручную.
- Ответственный (maintainer): Гайсин Ильдар Вильсурович, GitHub ildargiv, ildargiv@gmail.com.
- Выпуски: https://github.com/ildargiv/kopitehnik-converter/releases

## Что сделать после одобрения
1. В SignPath создать проект и политику подписи `release-signing` с ручным подтверждением.
2. Добавить в репозиторий секрет `SIGNPATH_API_TOKEN` и значения id организации и проекта.
3. В `release.yml` добавить шаг `signpath/github-action-submit-signing-request` между сборкой и контрольными суммами (суммы считать по подписанному файлу).

## Пока подписи нет
SmartScreen и антивирусы осторожнее относятся к неподписанному exe. Помогают сборка в Actions, контрольные суммы, VirusTotal и заявки о ложном срабатывании (`docs/antivirus/`).
