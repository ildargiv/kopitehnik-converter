# Contributing

Bug reports, ideas and pull requests are welcome.

## Reporting a problem

Open an [issue](https://github.com/ildargiv/kopitehnik-converter/issues) with the program version, the Windows version, the kind of file and the steps that lead to the problem. For OCR or PDF problems a sample page helps most; remove personal data first. Security problems go through [SECURITY.md](SECURITY.md).

## Running from source

Python 3.12.

```
pip install PySide6 pillow pillow-heif openpyxl "pymupdf<2" rapidocr opencv-python
python app.py
```

The README describes the structure of the code and how to add an interface language.

## Pull requests

- One change per pull request; say what you tested and on which files.
- `README.md` and `README.ru.md` are written by hand; the short READMEs in other languages are generated by `tools/make_readmes.py`, so edit that script and not the files.
- Do not commit build output.
